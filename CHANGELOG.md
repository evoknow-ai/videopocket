# Changelog

All notable changes to VideoPocket are documented here.

## 0.3.1 - 2026-08-09

- Organized downloads into source folders: `x`, `fb`, `ig`, `linkedin`, and `youtube`.
- Replaced long source titles with compact date, uploader, and media ID filenames.
- Applied the same organization to direct Chrome downloads and helper downloads.

## 0.3.0 - 2026-08-09

- Added the native VideoPocket Helper Mac application.
- Added universal Apple Silicon and Intel builds.
- Added Developer ID signing, hardened runtime, notarization, stapling, and verification.
- Added a distributable DMG with drag-to-Applications installation.
- Added a graphical helper installer and health status.

## 0.2.1 - 2026-08-08

- Added the Credits & About page.
- Added project attribution, Eat Sleep AI, changelog, and GitHub links.
- Prepared the complete public GitHub repository.

## 0.2.0 - 2026-08-08

- Added the double-click Mac installer and uninstaller.
- Moved the helper to a stable Application Support location.
- Added automatic Chrome-to-helper pairing.
- Added automatic startup at login.
- Added automatic FFmpeg installation through Homebrew.

## 0.1.4 - 2026-08-08

- Normalized completed downloads to H.264/AAC MP4.
- Corrected rotation handling for Facebook Reels.
- Added QuickTime-compatible fast-start output.

## 0.1.3 - 2026-08-08

- Fixed Facebook Reels detection.
- Added current-page URL fallback when a site hides its video element.

## 0.1.2 - 2026-08-08

- Fixed a helper configuration race during installation.

## 0.1.1 - 2026-08-08

- Added an isolated Python environment for compatibility with Homebrew Python.

## 0.1.0 - 2026-08-08

- Initial private release.
- Added X, Facebook, Instagram, LinkedIn, and YouTube adapters.
- Added direct MP4 downloads and the optional local helper.
